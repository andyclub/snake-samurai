# 听风大乱斗 (Kazeabc Ransen) - 管理员启动指南

要作为管理员启动游戏，请按照以下步骤操作：

1. **进入秘密入口**：在当前网页浏览器的 URL 地址栏末尾加上 `#/jec.on`。
   例如：`https://your-app-url.com/#/jec.on`
2. **触发回车**：按下回车键应用该 URL（如果没反应可以刷新一下页面）。
3. **使用管理员控制台**：此时页面右下角会浮现出一个黑色的命令行控制台。
4. **输入命令**：
   - `/jec.on` : 开启游戏（从“活动已结束”进入“招募中”大厅）。
   - `/jec.off` : 强制停止当前游戏，踢出所有玩家并返回关闭状态。
   - `/jec.restart` : 强制重开一局，直接返回大厅重新倒计时。
5. **正式开始**：在大厅等待 30 秒倒计时结束，系统会自动生成 5 个 NPC（Bot）并正式将所有玩家投入战场！

*(注：您也可以直接在 URL 地址栏输入 `#/jec.off` 或 `#/jec.restart` 来快速触发对应命令)*
